## Deskripsi
Tugas ini merupakan pembuatan website blog sederhana menggunakan HTML dan CSS. Artikel yang dibahas adalah mengenai **karhutla (kebakaran hutan dan lahan) di Kalimantan Selatan pada Oktober 2026**, termasuk dampaknya terhadap lingkungan dan masyarakat.

## Struktur File
- `index.html` — Berisi struktur halaman blog, judul artikel, isi artikel, kutipan, daftar, dan tautan referensi.
- `style.css` — Berisi pengaturan tampilan website, seperti warna, jenis huruf, jarak, ukuran konten, dan tata letak.

## Fitur Website
1. Menampilkan judul dan isi artikel blog.
2. Menggunakan HTML semantik untuk menyusun konten.
3. Memiliki kutipan dan daftar informasi.
4. Menyediakan tautan eksternal sebagai referensi berita.
5. Menggunakan CSS eksternal untuk mengatur tampilan halaman.
6. Menggunakan Google Fonts untuk memperindah tipografi.
7. Memiliki tata letak responsif sederhana dengan lebar konten maksimal 720 piksel.

## Teknologi yang Digunakan
- HTML5
- CSS3
- Google Fonts

## Cara Menjalankan
1. Buka folder `tugas4_2310010608`.
2. Klik dua kali file `index.html`.
3. Website akan terbuka melalui browser seperti Google Chrome atau Mozilla Firefox.

## Tujuan
Tugas ini bertujuan untuk memahami penggunaan HTML dalam menyusun artikel blog serta CSS dalam mengatur tampilan website agar lebih rapi, menarik, dan mudah dibaca.
